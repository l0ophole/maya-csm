# Goal
Text to speech using a clone of the voice of Sesame's voice chat agent, Maya

# Requirements:
- Locally hosted API or API hosted on free service like Colab or Kaggle
- Supports Laughing, Giggling, Whispering, etc. in text-to-speech output
- Compatible with SillyTavern
